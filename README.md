# CCA-F Drill — Pattern Key + 60Q

Interactive study tool for the Anthropic **Claude Certification Associate – Foundations (CCA-F)** exam.
Single self-contained HTML file — no build, no dependencies.

## Views
- **Key** — how to use the tool, 12 cheat-code meta-patterns, and one panel per question set (fingerprint, rule, every member question) with inline answer expansion.
- **Drill** — all 60 practice questions with per-question assists: hint, highlights, plain-words rephrases, pattern gists, in-practice snippets, and an Ask Claude clipboard packet. All-scroll or single-question view, filterable, flaggable.
- **Exam** — 1:1 simulation: 60 questions / 120 minutes, one per screen, pause/resume, per-question timing, Easy/Medium/Hard assist modes, and post-exam analytics (set ranking, downfall analysis, full review).

## Notes
- 11 answers verified directly against official Anthropic docs / MCP spec (sources linked in-app); the rest follow published guidance; 3 flagged as wording-sensitive debates.
- Dark mode default. Flags and exam state are in-memory only (reset on reload).

Built iteratively with Claude.
